## Bug Hunt Arena: Make learning to code feel like a game
- Beginners learn faster by fixing broken code than by reading theory, but practice problems are boring and quickly run out.
- Your mission: build an arena where AI creates the bugs and the learner hunts them down.
- Start here: the learner picks a language and gets a short program with something wrong in it.
- Make it yours: What makes a bug fair and fun to find? How can hints teach without giving the answer away? What keeps a learner coming back tomorrow?
